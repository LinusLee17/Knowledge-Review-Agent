# Evaluation

Evaluation runs before presentation refinement to document what "good" means.

Judge:
- factual correctness
- completeness
- specificity
- usefulness
- interview relevance
- clarity
- provenance preservation

Current scripts:

- `evaluate_consolidation.py`
- `evaluate_graph.py`

Rules:

- evaluation must run before Impeccable refinement
- quality gate failures block downstream polish
- evaluation should inspect technical quality, not visual polish
