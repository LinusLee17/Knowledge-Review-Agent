## Definition
Reinforcement Learning learns how an agent should act by interacting with an environment and using rewards as feedback. The objective is to maximize expected cumulative return over time.

## Why it Matters
Reinforcement Learning provides a formal way to support Control, Planning, Recommendation under stated assumptions.

## Core Intuition
Try actions, observe rewards, and improve the policy that chooses future actions.

## How it Works
Prerequisites: Markov Models, Probability.
1. Specify inputs and objective.
2. Apply method steps under stated assumptions.
3. Produce output, estimate, or decision.
4. Evaluate output against an explicit criterion.
Typical use context: Control, Planning, Recommendation.
Compare against: Dynamic Programming, Hidden Markov Models, Model Selection.
