## Definition
Type I Error occurs when a test rejects a true null hypothesis; its probability is the significance level α. It is used in Testing.

## Why it Matters
It matters because it connects a statistical decision with its possible failure mode, allowing error probabilities and consequences to be discussed explicitly.

## Core Intuition
Think of a hypothesis test as a controlled comparison: state a baseline, measure how far observed data move from it, then account for uncertainty before deciding.

## How it Works
1. State null and alternative claims.
2. Choose a test statistic and its null distribution.
3. Compute the statistic and p-value or critical-region decision.
4. Report the decision, uncertainty, effect size, and possible error.

## Key Components
- Null and alternative hypotheses
- Test statistic and null distribution
- Significance level or decision threshold
- Effect size and Type I/II error consequences
