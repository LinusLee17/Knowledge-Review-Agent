## Definition
A database is an organized collection of related data stored so it can be accessed, managed, and updated reliably. It separates durable organizational information from the applications that use it.

## Why it Matters
Database matters because it supports Analytics, Information Systems, Operational Data Management with an explicit concept and evidence trail.

## Core Intuition
Think of a database as a well-organized, shared store of related facts with rules that keep the facts usable.

## How it Works
1. Define the data items, relationships, and integrity rules.
2. Store the data through a database management system.
3. Query or update the data while the system enforces the defined rules.

## Key Components
- Stored data
- Schema or data model
- Database management system
- Integrity constraints
- Queries and updates

## Common Mistakes
- Treating a database as just a file collection without a schema or integrity rules.
- Ignoring access control, backup, and transaction requirements.
- Changing stored data without checking dependent applications or constraints.
