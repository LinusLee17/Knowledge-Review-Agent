# Knowledge Graph Builder

## Purpose

Create relationship data between canonical concepts.

## Inputs

- refined canonical concept records
- provenance-aware concept links

## Outputs

- graph node data
- graph edge data
- graph state index
- delta history for changed nodes and edges

## Relation examples

- prerequisite
- related
- used-in

## Notes

- no visualization in MVP
- keep structure simple enough for later graph tooling
- build incrementally from canonical concept metadata
- consume presentation-refined concept pages only
